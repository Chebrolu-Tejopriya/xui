# XUI

The KoinX design system. Components, tokens and icons, derived from Figma and
verified against it.

<p style={{ display: 'flex', gap: 24, font: 'var(--type-subtitle-1)', color: 'var(--content-secondary)' }}>
  <span><b style={{ color: 'var(--content-primary)' }}>{Object.keys(manifest.components).length}</b> components</span>
  <span><b style={{ color: 'var(--content-primary)' }}>{manifest.icons.count}</b> icons</span>
  <span><b style={{ color: 'var(--content-primary)' }}>{Object.values(manifest.tokens).flat().length}</b> tokens</span>
</p>

Those numbers come from the generated manifest, not from someone remembering to
update a sentence — the README said 38 components for a while after there were
43.

## Where to start

- **Installation** — install from GitHub, and what the version number means
- **Usage** — the two imports, icons, and the one styling rule that matters
- **Choosing Components** — which one to reach for when two look alike
- **Figma to Code** — how to get from a frame to XUI, and the traps in between
- **For Agents** — the MCP server, so an agent reads the system as tool calls
- **Generating UI** — prompting a model to build with XUI, and what to check
- **Status** — what is settled, and what is still waiting on a designer
- **FAQ** — the things that go wrong quietly, and what causes them
- **Contributing** — what gets in, and the checks it has to pass

Every component's own page sits under **Components**, with its props and each
state. **Foundations** holds the colours, type and labels; **Icons Library** holds the four icon families.
